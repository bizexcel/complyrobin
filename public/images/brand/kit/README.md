# ComplyRobin logo kit

Every format of the logo. The app itself only loads the files one folder up; these are for the marketing site, print, slides and anyone who asks for the logo.

- **Light and dark:** files without `-dark` are for light backgrounds; `-dark` files are for dark ones.
- **Small and large:** the logo is 80 px tall (small) or 600 px tall (large); the mark is 128 px or 1024 px.

| Format | Files | Use |
|---|---|---|
| SVG, one colour | `complyrobin-logo-black.svg`, `-white.svg`, `complyrobin-mark-black.svg`, `-white.svg` | stamps, embossing, one-colour print, watermarks |
| PNG, transparent | `complyrobin-logo-large.png`, `complyrobin-mark-small.png`, `-large.png` (and `-dark`) | slides, documents, avatars |
| JPEG | `complyrobin-logo-small.jpg`, `-large.jpg`, `complyrobin-mark-small.jpg`, `-large.jpg` (and `-dark`) | where PNG isn't accepted; on white, or on dark ink, with clear space included |
| WebP | the logo and the mark, small and large (and `-dark`) | websites; smaller than PNG |
| AVIF | the logo and the mark, large (and `-dark`) | websites; smaller still, newest browsers |
| PDF, vector | `complyrobin-logo.pdf`, `complyrobin-mark.pdf` (and `-dark`) | print shops and designers |
| Social | `avatar-1024.png`, `open-graph-1200x630.png` | profile pictures; link previews |

The full-colour SVGs and the small PNG for email are one folder up.

**Adobe Illustrator:** there is no `.ai` file. Illustrator opens the vector PDF and the SVG directly, and either can be saved as `.ai`. The wordmark is outlines, so no font is needed.

Never redraw, recolour or retype the logo. The rules are in `.ai/rules/brand.md`.
